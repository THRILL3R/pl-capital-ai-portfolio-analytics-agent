## Brand & Style

This design system establishes a high-conviction, calm, and institutional fintech interface for an automated portfolio intelligence platform. Rooted in established wealth management aesthetics, it blends data-dense institutional clarity with modern algorithmic agent ergonomics.

The aesthetic is precision-driven corporate modernism, characterized by:
- Deep corporate indigos juxtaposed against surgical white and light slate canvases.
- High-legibility numeric displays engineered for high-frequency portfolio review.
- Restrained color application where saturated emeralds and crimsons are reserved exclusively for financial performance metrics (alpha, delta, gain/loss).
- Crisp structural definition using fine hairline strokes and disciplined pill-shaped interactive anchors to signal intent and responsive feedback.

## Colors

The color palette is built on strict systemic governance to prevent visual noise while maximizing financial legibility:
- **Brand Green (`#1FB15A`) & Semantic Green (`#22C55E`):** Strictly reserved for positive delta, positive yields, financial outperformance, and isolated brand anchor marks. It must never be used for general buttons, decorative tags, or multi-class categorical visualizations.
- **Categorical Series:** Data charts rely on the eight-step analytical spectrum (`#0000A0`, `#4C4CCC`, `#7D7DD0`, `#B6B6F7`, `#3922D1`, `#272756`, `#6B7280`, `#D0D0FC`), completely omitting green to ensure financial gain signals remain unambiguous.
- **Primary Gradient:** Use `linear-gradient(144deg, #4C4CCC 40.85%, #0000A0 98.66%)` for key agent executive summaries, high-impact hero banners, and primary workflow entry cards.
- **Violet Accent (`#3922D1`):** Applied exclusively to major KPI metric figures, active routing state borders, and distinct graphic offset shadows.

## Typography

The type system is calibrated for precision analytics, structured data inspection, and computational outputs.

- **Type Scale Execution:** Metric KPIs utilize weights `700` and `800` to anchor scanning patterns across dense financial dashboards. Headings leverage rich indigos (`#0F0F83` and `#07075A`) rather than pure black, ensuring brand cohesion and reduced optical vibration against white surfaces.
- **Numbers and Metrics:** Tabular figures must be enabled (`font-variant-numeric: tabular-nums`) across all analytical data components, financial tables, ticker displays, and dynamic portfolio allocations to prevent jitter during real-time valuation updates.
- **Table Data:** Header labels are set in uppercase at `11px` weight `700` with expanded letter spacing (`0.05em`) in `#6B7280`, providing distinct separation between meta-labels and transactional row contents.

## Layout & Spacing

The layout is built on a 12-column responsive fluid grid designed to maximize screen real estate for deep analytical exploration while enforcing strict visual rhythm.

- **Breakpoints & Grid Geometry:**
  - **Desktop (≥1200px):** 12-column fluid grid, 24px (`1.5rem`) gutters, 32px (`2rem`) outer margins. Side panels for prompt inputs and active agent threads conform to a fixed 380px rail, while analytical canvas areas flex across the remaining columns.
  - **Tablet (768px – 1199px):** 8-column layout, 16px (`1rem`) gutters, 24px (`1.5rem`) margins. Multi-metric KPI rows collapse from 4 columns to 2x2 matrices.
  - **Mobile (<768px):** 4-column layout, 12px gutters, 16px (`1rem`) margins. Side-by-side data grids collapse to vertically stacked cards with horizontal scroll for wide financial statements.
- **Density Rhythms:**
  - `space-xs` (4px) and `space-sm` (8px): Micro-spacing within component internals (pill padding, badges, segmented controls, table cell padding).
  - `space-md` (16px) and `space-lg` (24px): Standard component gaps, form field stacks, and card-to-card structural pacing.
  - `space-xl` (32px): Major thematic module separations and analytical section breaks.

## Elevation & Depth

Visual hierarchy uses crisp surface-container contrast coupled with intentional structural drops rather than ubiquitous deep shadows.

- **Tonal Tiers:**
  - **Canvas Base:** `#F8FAFC` page tint provides an anti-glare operational floor.
  - **Component Surface:** `#FFFFFF` cards, floating inspect panels, and active tables sit cleanly on top of the tinted base with razor-thin `#E2E8F0` borders.
  - **Callout & AI Context Surface:** Light lavender tints (`#F5F5FF`) highlight natural-language agent outputs, query reasoning chains, and algorithmic portfolio recommendations.
- **Shadow Philosophy:**
  - **Soft Indigo Ambient (Elevation 1):** `5px 3px 12px rgba(39, 39, 86, 0.10)`. Used on hovering data cards, analytical modal drawers, and floating toolbars. The tinted indigo profile blends seamlessly with brand geometry without dull gray contamination.
  - **Hard Offset Accent (Elevation 2 - Selected State):** `4px 4px 0px #3922D1`. Applied exclusively to selected investment route cards, focused interactive strategy options, and active agent execution paths. This provides an unambiguous, technical confirmation of state selection.

## Shapes

The interface balances friendly algorithmic interactivity with institutional financial rigor through a dual-radius methodology:

- **Pill Radius (Fully Rounded / 65px):** Reserved for interactive control endpoints: buttons, filter chips, prompt input search capsules, category toggle pills, and delta status badges. This immediately differentiates actionable controls from observational data surfaces.
- **Card & Data Radii Hierarchy:**
  - **Large Analytical Modules (24px):** Executive overview containers, primary hero gradient banners, and macro asset allocation wrappers.
  - **Medium Containers (12px):** Secondary metric cards, benchmark comparison graphs, and interactive chart panels.
  - **Data Precision Elements (8px):** Quantitative data tables, standard form inputs, modal dialogs, and tabular metric grids.

## Components

### Buttons
- **Primary:** Background `#4C4CCC`, text `#FFFFFF`, height 40px (or 36px for dense tables), full pill radius (65px), horizontal padding `1.25rem`. Hover state changes background to `#3636BC`. Active/focus adds an indigo outline ring with 2px offset.
- **Secondary:** Surface `#FFFFFF`, border 1.5px solid `#27277A`, text `#27277A`, full pill radius. Hover: surface tints to `#F5F5FF`.
- **Agent Action (Gradient):** `linear-gradient(144deg, #4C4CCC 40.85%, #0000A0 98.66%)`, white text, soft indigo shadow. Used for generating portfolio rebalancing plans or executing agent trades.

### Chips & Badges
- **Filter Chips:** Pill-shaped, border 1px solid `#E2E8F0`, background `#FFFFFF`, text `#555555`. Selected: background `#0000A0`, text `#FFFFFF`, border-color `#0000A0`.
- **Financial Delta Badges:** Full pill radius (65px), padding 2px 10px, typography `label-sm`.
  - **Positive Gain:** Text `#22C55E`, background `#D7FFE5`. Always prefixed with `+` or an upward trend chevron.
  - **Negative Drawdown:** Text `#E53935`, background `#FDECEA`. Always prefixed with `-` or a downward trend chevron.

### Form Inputs & Agent Prompt Bars
- **Text & Numeric Inputs:** 8px radius, height 40px, background `#E8E8FF`, border 1px solid transparent, text `#212529`. Focus: background `#FFFFFF`, border-color `#4C4CCC`, smooth transition.
- **Agent Conversational Search Bar:** 65px pill radius, height 52px, background `#FFFFFF`, border 1px solid `#E2E8F0`, interior padding 8px 16px. Contains embedded pill submit action button. Displays soft indigo shadow (`5px 3px 12px rgba(39, 39, 86, 0.10)`).

### Data Tables
- **Container:** 8px corner radius, border 1px solid `#E2E8F0`, background `#FFFFFF`.
- **Header Row:** Background `#F7F7F7`, height 40px, text uppercase `11px` bold in `#6B7280`. Bottom border 1px solid `#E2E8F0`.
- **Data Rows:** Height 48px, horizontal borders 1px solid `#F0F0F0`, typography `13px` tabular numbers. Row hover state: `#F8FAFC`.

### Cards & Route Selection Cards
- **Standard Metric Card:** 12px radius, background `#FFFFFF`, border 1px solid `#E2E8F0`, padding 16px. Contains metric label in `#6B7280`, KPI value in `#3922D1` (`headline-kpi`), and embedded performance delta badge.
- **Selected Route Card:** 12px radius, background `#FFFFFF`, border 2px solid `#3922D1`, box-shadow `4px 4px 0px #3922D1`. Conveys the chosen algorithmic rebalance or optimization pathway.

### Agent Insight Callouts
- **Recommendation Container:** 12px radius, background `#F5F5FF`, border-left 4px solid `#4C4CCC`, padding 16px. Body text set in `#212529` with key highlight tokens rendered in `#07075A` bold.
