## Method

- **Prompt (identical for all models):** "You are an AI portfolio analytics assistant. Explain how to calculate Technology sector exposure in an investment portfolio. Reply with a concise, technically correct answer."
- One request per model, sequential, strongest first; `max_output_tokens=1024` (thinking tokens count toward it); client timeout 60s; SDK retries disabled.
- Stop rule: a `429` that indicates exhausted quota stops all further tests. A `429` with `limit: 0` means the model has no free quota for this project and is recorded, not treated as exhaustion.
- **Free-tier evidence:** https://ai.google.dev/gemini-api/docs/pricing (redirects to https://aistudio.google.com/docs/pricing), Standard tier, checked 2026-11-09. Models absent from that page are *unverified* and were not sent generation requests.
- Response time is wall-clock for one request from this machine; it is a single sample, not a latency benchmark.

To calculate Technology sector exposure, follow these steps:

### 1. Categorize Holdings
Identify each security in the portfolio according to a standardized industry classification system, such as **GICS** (Global Industry Classification Standard). Assign each holding to its primary sector (e.g., Information Technology).

### 2. Calculate Position Weight
Determine the market value for each individual holding ($V_i$) relative to the total portfolio market value ($V_p$):
$$w_i = \frac{V_i}{V_p}$$

### 3. Aggregate Sector Weight
Sum the weights of all individual holdings classified within the Technology sector:
$$\text{Tech Exposure} = \sum w_{\text{tech}}$$
